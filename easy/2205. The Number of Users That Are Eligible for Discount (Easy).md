# Question 2205: The Number of Users That Are Eligible for Discount

**LeetCode URL:** https://leetcode.com/problems/the-number-of-users-that-are-eligible-for-discount/

## Description

Drafted from this solution SQL: write a query on `purchases` to return `user_cnt`. Apply filter conditions: (DATE_TRUNC('DAY',time_stamp) BETWEEN '2022-03-08' AND '2022-03-20') AND amount >= 1000.

## Table Schema Structure

```sql
Create table If Not Exists Purchases (user_id int, time_stamp datetime, amount int);
```

## Sample Input Data

```sql
insert into Purchases (user_id, time_stamp, amount) values ('1', '2022-04-20 09:03:00', '4416');
insert into Purchases (user_id, time_stamp, amount) values ('2', '2022-03-19 19:24:02', '678');
insert into Purchases (user_id, time_stamp, amount) values ('3', '2022-03-18 12:03:09', '4523');
insert into Purchases (user_id, time_stamp, amount) values ('3', '2022-03-30 09:43:42', '626');
```

## Expected Output Data

```text
+----------+
| user_cnt |
+----------+
| sample   |
+----------+
```

## SQL Solution

```sql
SELECT COUNT(DISTINCT user_id) AS user_cnt
FROM purchases_2205
WHERE (DATE_TRUNC('DAY',time_stamp) BETWEEN '2022-03-08' AND '2022-03-20') AND amount >= 1000;
```
