# Question 612: Shortest Distance in a Plane

**LeetCode URL:** https://leetcode.com/problems/shortest-distance-in-a-plane/

## Description

Drafted from this solution SQL: write a query on `point_2d` to return `shortest`.

## Table Schema Structure

```sql
Create Table If Not Exists Point2D (x int not null, y int not null);
```

## Sample Input Data

```sql
insert into Point2D (x, y) values ('-1', '-1');
insert into Point2D (x, y) values ('0', '0');
insert into Point2D (x, y) values ('-1', '-2');
```

## Expected Output Data

```text
+----------+
| shortest |
+----------+
| sample   |
+----------+
```

## SQL Solution

```sql
SELECT ROUND(MIN(SQRT(POWER(a.x-b.x,2)+POWER(a.y-b.y,2)))::NUMERIC,2) AS shortest
FROM point_2d_612 a
JOIN point_2d_612 b ON (a.x,a.y) <> (b.x,b.y);
```
